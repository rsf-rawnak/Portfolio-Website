01 About PROFILE — CSE / UAP

I'm a Machine Learning Engineer — final-year Computer Science and Engineering student at the University of Asia Pacific, finishing an undergraduate thesis on unsupervised tool condition monitoring for CNC milling. FFT-based spectral features, LOF and OC-SVM anomaly detection, cross-tool threshold transferability via CORAL domain adaptation.

That's the core of what I do: building detection and classification systems where the signal isn't handed to you clean. I've applied the same mindset to NLP — a workplace harassment severity classifier, an AI-generated project detector trained across three LLM sources.

Alongside the engineering, I run WISHEND, an apparel brand I built and ship myself.

I'm looking for ML/dev internship roles where I can work on real detection and classification problems, not toy datasets.

02 Projects 5 SHIPPED / IN PROGRESS
PRJ-001 · THESIS
Unsupervised Tool Condition Monitoring for CNC Milling
Defense Dec 2026

Detects tool wear in CNC milling using FFT-based spectral features, with Local Outlier Factor and One-Class SVM for anomaly detection. Includes cross-tool threshold transferability via CORAL domain adaptation and robust covariance estimation, evaluated against the UC Berkeley Milling Dataset.

Methods
LOF · OC-SVM · CORAL
Dataset
KIT Karlsruhe Dataset
Team
3 · Supervised
